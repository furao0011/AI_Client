# 服务端对接需求文档

## 一、项目背景

当前 AI 问答 App 客户端已实现基于 Room 的本地数据存储和直接调用 OpenAI 兼容 API 的功能。为提升用户体验和数据安全性，需要将核心业务迁移到服务端，包括：

1. **用户鉴权**：服务端管理用户信息，实现安全的登录注册机制
2. **数据同步**：会话和消息数据存储在服务端，支持多设备同步
3. **图片托管**：图片上传到服务端，生成外链供 AI API 使用
4. **AI 网关**：服务端作为 AI API 网关，统一管理 API Key，支持 SSE 流式转发

---

## 二、功能需求详述

### 2.1 用户鉴权系统

#### 功能描述
- 用户注册：用户名、密码、邮箱（可选）
- 用户登录：返回 JWT Token，Token 有效期 7 天
- Token 刷新：支持 Token 续期
- 用户信息：获取/更新用户资料（头像、昵称等）
- 登出：客户端清除 Token

#### 安全要求
- 密码使用 BCrypt 加密存储
- JWT 签名使用 HS256 算法
- 所有 API 请求（除登录注册外）需携带 Authorization Header

### 2.2 会话与消息管理

#### 会话管理
- 创建会话：生成唯一 ID，可指定初始标题
- 获取会话列表：支持分页，按更新时间倒序
- 更新会话：修改标题
- 删除会话：级联删除所有消息
- 清空所有历史：删除用户的所有会话和消息

#### 消息管理
- 发送消息：支持文本和图片消息
- 获取消息列表：按会话 ID 查询，支持分页
- 编辑消息：修改消息内容，触发重新生成 AI 回复
- 删除消息：删除指定消息及之后的所有消息

### 2.3 图片上传与托管

#### 功能描述
- 客户端上传图片（Base64 或 Multipart）
- 服务端保存图片到本地/对象存储
- 生成可访问的图片 URL（外链）
- 图片 URL 作为消息内容存储

#### 技术要点
- 支持 JPEG、PNG、GIF、WebP 格式
- 单张图片限制 10MB
- 图片 URL 格式：`https://{server}/api/images/{imageId}`
- 可选：图片访问鉴权（私有 URL）

### 2.4 AI 对话服务网关

#### 功能描述
服务端作为 AI API 网关，统一转发请求到 ModelScope API：

- **默认 API 配置**：
  - Base URL: `https://api-inference.modelscope.cn`
  - API Key: 服务端统一管理，不暴露给客户端
  - Model: 可配置，默认 `qwen-turbo`

- **请求转发**：
  - 客户端请求 → 服务端网关 → ModelScope API
  - 服务端添加真实 API Key
  - 完整转发响应（包括 SSE 流式响应）

- **兼容性**：
  - 网关接口完全兼容 OpenAI API 格式
  - 客户端可直接使用现有的 `OpenAiService` 调用网关
  - 支持 `/v1/chat/completions` 端点

#### SSE 流式响应转发
- 服务端建立到 ModelScope 的流式连接
- 实时转发 SSE 事件到客户端
- 保持 `data: {...}` 和 `data: [DONE]` 格式

## 三、客户端数据结构（参考对齐）

### User（用户）
```kotlin
data class User(
    val id: String,           // 用户唯一 ID
    val username: String,     // 用户名
    val email: String,        // 邮箱
    val avatarUrl: String?    // 头像 URL
)
```

### Session（会话）
```kotlin
data class Session(
    val id: String,           // 会话唯一 ID
    val title: String,        // 会话标题
    val lastMessage: String,  // 最后一条消息预览
    val timestamp: Long       // 最后更新时间戳
)
```

### Message（消息）
```kotlin
data class Message(
    val id: String,           // 消息唯一 ID
    val sessionId: String,    // 所属会话 ID
    val content: String,      // 消息文本内容
    val isUser: Boolean,      // true=用户消息, false=AI消息
    val timestamp: Long,      // 消息时间戳
    val imageUrl: String?     // 图片 URL（替代原 imageBase64）
)
```

## 四、非功能需求

### 性能
- API 响应时间 < 500ms（不含 AI 生成时间）
- 支持 1000 并发用户
- SSE 连接超时 5 分钟

### 安全
- HTTPS 强制
- SQL 注入防护
- XSS 防护
- 请求频率限制（Rate Limiting）

### 可用性
- 服务可用性 > 99.9%
- 数据定期备份

## 六、开发优先级

1. **P0 - 核心功能**
   - 用户注册/登录/鉴权
   - AI 网关（SSE 转发）
   - 图片上传与外链

2. **P1 - 数据同步**
   - 会话 CRUD
   - 消息 CRUD

3. **P2 - 增强功能**
   - Token 刷新
   - 用户资料管理
   - 数据导出
